# factorio-forge

Генерация чертежей Factorio по описанию — под твой сейв, твою сборку модов и твой
стиль постройки.

[English version](README.md)

> **Статус: ранняя разработка.** Готов слой путей и скелет проекта; система
> профилей, мод-компаньон, рендер и генераторы ещё пишутся. Пользоваться пока
> нечем.

## Что это

Большинство инструментов для чертежей выдают universally правильный дизайн,
который потом всё равно приходится переделывать под свою базу. Задача этого
проекта — выдавать чертёж, который встаёт в **твою** базу как есть: та же сетка
ситиблоков, тот же шаг рельсов, тот же тир лент, та же длина поездов, и рецепты,
которые реально существуют в твоей сборке.

Для этого на каждый сейв заводится **профиль** — набор модов, игровые данные в том
виде, в каком их разрешает эта сборка, и стиль постройки, измеренный по чертежам,
которыми ты уже пользуешься. Генерация идёт внутри соглашений этого профиля.

## Как устроено

- **Строки чертежей, данные о сущностях и коллизии** берутся из
  [`factorio-draftsman`](https://github.com/redruin1/factorio-draftsman) —
  библиотека прогоняет настоящий Lua data lifecycle Factorio по установленным
  модам. Взаимодействия модов разрешаются правилами самой игры, а не угадываются.
- **База и состояние исследований** выгружаются небольшим модом-компаньоном прямо
  из игры. Файлы сохранений напрямую не парсятся: их формат внутренний и
  привязан к версии, поэтому парсером выступает сама игра.
- **Стиль постройки** измеряется по эталонным чертежам, а не выспрашивается
  анкетой.

## Требования

- Factorio 2.0 (любая сборка модов, Space Age по желанию)
- Python 3.10 или новее

## Установка

```bash
git clone <этот-репозиторий>
cd factorio-forge
python -m venv .venv
.venv/Scripts/activate      # Windows
source .venv/bin/activate   # Linux / macOS
pip install -e ".[dev]"
```

Дальше проверь, что игра найдена:

```bash
python -m factorio_forge.paths
```

Все пути определяются автоматически, в первую очередь по тем, что Factorio сама
записала в свой последний лог. Это работает для библиотек Steam на любом диске,
для standalone-установок и на всех трёх платформах. Настраивать вручную ничего не
нужно, если определение не сорвалось.

## Где что хранится

Код лежит в репозитории. Твои данные — нет.

| Что | Где |
| --- | --- |
| Профили, извлечённые игровые данные, локальный конфиг | `%APPDATA%\factorio-forge\` (Windows) |
| | `~/.local/share/factorio-forge/` (Linux) |
| | `~/Library/Application Support/factorio-forge/` (macOS) |

Расположение переопределяется переменной окружения `FACTORIO_FORGE_HOME`.
Расположение самой игры — переменными `FACTORIO_PATH` и `FACTORIO_USER_DIR`, но
обычно оно определяется само.

Извлечённые игровые данные генерируются на твоей машине и никогда не коммитятся:
они зависят от версии игры и набора модов, и распространять их мы не вправе.
